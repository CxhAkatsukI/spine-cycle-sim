# Frozen Evidence

This directory contains reports, manifests, tables, and negative results from
multiple implementation eras. It is an archive of evidence, not a single
currently accepted experiment.

## Where To Start

- For paper-facing outputs: [Figures 7--11 handoff](../evaluation_refresh_20260810/figure7_10_handoff_v1/README.md).
- For the calibration question behind a report: [calibration guide](../experiments/calibration/README.md).
- For workload/comparison context: [comparison guide](../experiments/comparisons/README.md).
- For model and resource analysis: [cost-model guide](../experiments/cost_models/README.md).

## Preservation Rules

Existing files and paths here were not moved or rewritten during documentation
organization. Profiles, plugin hashes, input identities, and the selected
manifest determine which evidence can be combined. A newer filename is not
automatically a superseding result.

Some archived explanations mention former `docs/<record>.md` paths. Look up
those records in the [relocation map](../repository/document_locations.json).
The original text is retained to preserve frozen package identities.
