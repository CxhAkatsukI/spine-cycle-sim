\begin{abstract}
This evidence pack evaluates normalized Spine and GraSU+ReGraph architectures
with an execution-driven simulator and routed FPGA feasibility artifacts.  The
reported compact-slice comparison covers weighted SSSP, full PageRank, and
thresholded residual PageRank; every performance row is admitted only after
architecture-precision, independent mathematical, and cross-system final-state
checks pass.  Claims are scoped explicitly below so that compact-slice
simulation, dense-update evidence, HBM-only energy, and non-iso-functional FPGA
builds are not conflated.
\end{abstract}

\vspace{0.6em}
\noindent\textbf{Claim rule.}
Every plotted performance row must pass the architecture-precision oracle,
the independent mathematical oracle, and the cross-system final-state check.
Compact slices and larger validation slices are reported as separate
populations.  The 540,000-edge AskUbuntu experiment is multi-partition but is
still a slice, not a full-dataset claim.
