# Current-FPGA Spine component calibration v14

## Purpose

V14 replaces the failed v13 edge/task-only timing map with a component model
whose inputs are generated by the execution-driven simulator itself. It does
not alter the simulator, routed HLS identity, workload semantics, or memory
traffic. It maps simulator component work to routed FPGA event cycles while
preserving reader/compute overlap.

The immutable simulator plugin is:

```text
cpp/sst/build/sst-current-fpga-v12/libspine_cycle.so
sha256=f1fca617de22877ca675c72c6877444c029af8b83d4c30a25754d85f7e324b70
```

## Model and evidence roles

Calibration uses AU, SU, WK, R19, and the previously revealed PK result. SO,
LJ, and LJ08 are hash-pinned independent holdouts. Their v14 result directory
was empty when the model was frozen.

For each algorithm:

- maintenance is a non-negative affine map of simulator maintenance cycles;
- reader uses completed AXI parent requests and execution-driven reader cycles;
- compute uses rounds, completed AXI parent requests, and execution-driven
  compute cycles;
- routed iterative time is `max(reader, compute)` plus a non-negative per-round
  overlap residual;
- zero-round residual PageRank is maintenance-only.

Every admitted row must independently pass correctness, structural-work, FIFO,
request, byte, and locality-ledger checks. Holdout rows are never fit.

## Development transfer check

Leave-one-dataset-out is reported only as development evidence:

| Algorithm | Median total abs. error | Max total abs. error |
| --- | ---: | ---: |
| Weighted SSSP | 11.22% | 21.30% |
| Connected Components | 28.21% | 34.00% |
| Thresholded Residual PageRank | 9.95% | 15.28% |

CC reader transfer is the explicit risk: its development reader error is
28.78% median and 35.27% maximum. V14 is therefore not accepted by these fit
numbers. Only the frozen SO/LJ/LJ08 analysis can accept or reject it.
