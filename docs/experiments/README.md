# Experiment Guide

Choose the question before choosing a result file.

| Question | Read this |
| --- | --- |
| Which component timings were compared with hardware, and which failed? | [Calibration records](calibration/README.md) |
| What workload, initialization, and timing boundary were compared? | [Comparison records](comparisons/README.md) |
| How were stage costs, traffic, and energy analyzed? | [Cost-model records](cost_models/README.md) |

For the handoff to the paper author, start with the
[Figures 7--11 package](../evaluation_refresh_20260810/figure7_10_handoff_v1/README.md)
and its [corrected evidence audit](../evaluation_refresh_20260810/figure7_10_handoff_v1/EVIDENCE_AUDIT_20260917.md).
The files in this section are dated investigation records; a failed holdout
remains visible and is not upgraded by being placed next to a passing result.

Raw inputs and reports remain under [evidence](../evidence/README.md).
Earlier campaign planning and execution history are in
[history](../history/README.md). This organization did not rerun experiments
or change any calibration coefficient.
