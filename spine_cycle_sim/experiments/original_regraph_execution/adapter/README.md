# PMA Input Control

Start with the [implementation guide](../../../../docs/implementation/grasu_regraph/original_regraph_adapter_source.md)
and [study results](../../../../docs/experiments/comparisons/grasu_regraph_stage_validation/ADAPTER_SOURCE.md).

Preparation preserves A4 logical tasks and edge multiplicity in a source16
read-only PMA ABI. Analysis independently validates complete layouts and
observed packets. Study owns bounded execution; validation owns rejection
controls; regression admits only the shared wiring extraction; delivery
rechecks and packages evidence. Shared subprocess execution and author-host
admission are reused, not copied.

The source probe is not connected as a timed producer in A4. Finite adapter
timing, A4/B overlap and integrated overhead remain separate required gates.
