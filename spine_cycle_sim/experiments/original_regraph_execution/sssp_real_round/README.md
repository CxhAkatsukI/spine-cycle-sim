# Real-Topology Weighted-SSSP Resident Round

This owner extends the optional local SSSP control to an unchanged author-host
DBG/task capture and the actual sharded-K4 model. It is not the original PR
publication, a converged-update benchmark, or an FPGA timing measurement.

| Module | Responsibility |
| --- | --- |
| `preparation.py` | Preserve author vertex/task order; overlay unique weighted edges and independently prepared old state |
| `evidence.py` | Pin the local synthesized SSSP Apply schedule and its limited scope |
| `analysis.py` | Complete replicas, traffic, registration-order and memory-service sensitivity admission |
| `study.py` | Fresh bounded build, exact old-path regression, author capture and fixed twelve-run matrix |
| `recheck.py` | Re-admit raw numerical output, regenerated overlays, pinned dependencies and legacy equality |
| `delivery.py` | Seal complete inputs/states, negative attempts and verification logs into an indexed archive |

C++ decoding/oracle and execution live separately in
`cpp/tests/original_regraph/sssp/real_input.hpp` and `real_round.cpp`. Shared
whole-graph wiring defaults to unchanged PR. Local SSSP options are explicit.

Read the [study contract and results](../../../../docs/experiments/comparisons/grasu_regraph_stage_validation/actual_sharded_k4/matched_a4/sssp_real_round/README.md)
before interpreting a cycle ratio. In particular, one destination partition
uses only one K4 worker; common mock-memory service does not make the two
architectures' ports, read/write credits or state publication identical.
