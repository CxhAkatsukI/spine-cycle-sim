# Original Big Validation Owner

This subpackage belongs to the existing original-ReGraph validation family.
It validates a separate Big routing/Gather path, not a hidden Little mode or
a whole-R publication-speed claim.

| Module | Responsibility |
| --- | --- |
| `sources.py` | Clean source-pin check, original 11+3 generation, independent original Big capture and compiler dependencies |
| `study.py` | Fixed bounded execution, repeats, malformed captures and independent UBSan executables |
| `analysis.py` | Typed geometry/timing, complete source comparison and finite-pressure admission |
| `regression.py` | Exact existing-component and eight-row complete-A4 comparisons |
| `delivery.py` | Recheck admitted evidence and package indexed raw results |
| `frontend_sources.py` | Separate original generator/cache-wrapper/Scatter capture |
| `frontend_study.py` | Finite memory/Scatter matrix, repeats, malformed captures and legacy gates |
| `frontend_analysis.py` | Source/cache/physical-byte and finite-pressure admission |
| `frontend_delivery.py` | Separate memory/frontend raw package and verification |

The thin CLI is `scripts/run_original_regraph_big_validation.py`; the fixed
contract is `configs/experiments/original_regraph_big_gather_validation_v1.json`.
The [study guide](../../../../docs/experiments/comparisons/grasu_regraph_stage_validation/BIG_ROUTING_GATHER.md)
owns accepted results, limitations and reproduction commands.
The [memory/frontend checkpoint](../../../../docs/experiments/comparisons/grasu_regraph_stage_validation/BIG_MEMORY_FRONTEND.md)
has its own contract and thin `run_original_regraph_big_frontend_validation.py`
entry point; its boundary excludes Gather and mixed-system timing.
