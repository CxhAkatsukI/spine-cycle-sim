# Original GraSU Source Control

This package owns optional original-source G functional composition, not
the production direct-cache port or a fitted timing model. See the
[implementation guide](../../../../docs/implementation/grasu_regraph/original_grasu_source_path.md)
and [study report](../../../../docs/experiments/comparisons/grasu_regraph_stage_validation/GRASU_SOURCE_PATH.md).

Review `fixtures.py` for the already-reserved input boundary, `preparation.py`
for source/old-evidence admission, `study.py` for bounded runs, `analysis.py`
for independent checks, `validation.py` for actual-output rejection controls,
and `delivery.py` for immutable packaging. Shared safe execution remains in
the parent package; no duplicate subprocess launcher is introduced.
